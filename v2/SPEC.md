# 리미키미 2.0 — 공통 화면 명세 (iOS SwiftUI · Android React Native · Web)

> 세 벌(iOS·Android·Web)이 **이 문서 하나**를 따른다. 새 기능은 여기부터 고치고 세 곳에 반영한다.
> 서버(Vercel `api/`, Supabase)는 그대로 쓴다. 오너 확정 2026-09-17: 세 플랫폼 **같은 날 2.0 동시 출시**, 1.x 추가 배포 없음.

## 0. 원칙
- iOS = SwiftUI(iOS 26+, Friday `~/Documents/friday/app/friday-ios` 방식). Android = React Native/Expo(Justin `~/Documents/justin/mobile` 셸). Web = 현재 React(`src/`)를 이 명세대로 재스타일·재배선.
- **UI 글꼴은 시스템 글꼴**(SF·Apple SD Gothic Neo / Roboto·Noto Sans KR). 브랜드 글꼴 없음. **로고는 그대로**(`public/logo*.svg` 하트 워드마크).
- **큰 제목(Large Title) 안 씀.** 홈은 로고가 제목. 안쪽 화면은 상단 바 가운데 작은 제목.
- 유리 재질(blur)은 탭바·상단 바에만. 카드·리스트엔 안 씀.
- 애니메이션은 transform/opacity만. 종료는 진입보다 빠르게. 탭 전환 0ms.

## 2. 정보 구조 (탭 5슬롯)
갤러리 · 필터 · **⦿카메라(가운데, 떠 있음)** · 내 사진 · 프로필
- 갤러리: 로고 헤더(크레딧 칩 + 아바타) → 카테고리 칩(필터 칩 없음) → 추천 줄 → 새로 나왔어요 줄 → 카테고리별 줄
- 필터 탭: 필름 · 카메라 · 재미 세 그룹 가로줄, 맨 위 "카메라로 찍기"
- 내 사진: 서버 갤러리 그리드 + 맨 위 **진행 카드**(생성 중)
- 프로필: 크레딧·스토어·**초대(여기로 이동)**·알림 설정·계정·법적 고지

## 3. 흐름 (확정)
### 첫 실행
가이드 1장 → 홈. **팝업 겹치기 금지.** ATT는 첫 생성 완료 후, 알림 권한은 "새 컨셉 알림 켜기"를 누를 때.
### 로그인 (모든 도구 공통, 필수)
- 시점: **'만들기' 버튼**, 필터 사진 고르기 직전, 카메라 열기 직전.
- 제공자: Apple(네이티브 시트) · 카카오 · 네이버 · Google(웹 세션). Supabase OAuth 그대로, 딥링크 `com.rimikimi.app://login-callback`.
- 로그인 뒤 **하던 동작 자동 재개**(1.x `rimikimi_pending_tool`/`pendingContinue` 와 같은 뜻).
### 생성 (컨셉)
컨셉 카드 → **옵션 화면**(푸시) : 상단 바 제목=컨셉명, 컨셉 미리보기 크게, "내 사진: 등록된 사진 사용 · 변경" 카드 한 줄(사진 없으면 여기서 고르기), 컨셉별 옵션(드레스룸: 의상 5장·스타일 거울/일상·장수 / 인생네컷: 컷수·스타일 / 배치 장수) → **만들기** → (로그인 → 크레딧 부족이면 팩·구독·초대 시트) → **홈으로 복귀 + 내 사진 진행 카드** → 완료 시 푸시 + 카드가 결과로 → 결과 화면.
- STEP 02(사진 업로드) 화면 **없음**. 매직부스(일회용 사진)·커플(상대 사진)은 옵션 화면 안 슬롯으로.
### 결과
사진 크게 · "내 사진에 저장됐어요 · 앨범에도 저장" (사실대로) · 앨범 저장 · 다듬기(편집기) · 공유 · **한 장 더 · 비슷한 컨셉**. 첫 생성 완료 직후 1회: ATT 팝업 → 초대 카드.
### 필터
필터 탭 → 프리셋 → (로그인) → 사진 최대 10장 → 편집기 → 저장/공유.
### 카메라
가운데 버튼 → (로그인) → 뷰파인더에 필터 라이브(저장본과 같은 필터 코드) → 셔터 → **즉시 앨범 저장** → "다듬기 · 공유" 버튼(편집기는 원할 때).
### 정방향 맞춤 (신규)
사진이 3:4가 아니면 편집기·카메라 결과·복원 컨셉에서 자동 제안. EXIF로 바로 세우기 → ① 잘라 맞춤(얼굴 기준 크롭, 무료) ② 채워 맞춤(서버 `/api/generate?fit=outpaint`, 원본 픽셀 유지 + 바깥 채움, 1크레딧).
### 크레딧 부족
토스트 대신 시트: 팩 3개 · 구독 1개 · "친구 초대로 무료 3장". 구매 즉시 하던 생성 이어짐.

## 4. 서버 계약 (그대로)
클라이언트가 쓰는 엔드포인트: `POST /api/generate`(응답 `{mimeType, base64, images:[{mimeType,base64}], credits, quotaUsed, quotaLimit}`; 얼굴 precheck `{ok,hasFace}`), `GET /api/quota`, `GET/POST /api/gallery`, `GET /api/popular`, `GET /concepts.json`(카테고리·`fourcutStyles` 포함), `POST /api/iap/grant`, `POST /api/referral/claim`, `POST /api/account/delete`. 정확한 요청 필드는 `src/PortraitStudio.jsx`의 `generateImage()`와 각 fetch 호출을 그대로 옮긴다.
- 컨셉 원격 로드, 매일 20:00 드롭, 완료 푸시(`notifyDone`), 백그라운드 복구(갤러리 폴링)는 서버 그대로.
- 결제: RevenueCat, 상품 ID `rimikimi.pack.intro/mini/standard/pro`, `rimikimi.sub.plus.weekly/monthly/annual`. **적립 이중 지급 결함**(grant + webhook 거래ID 불일치, 구독 갱신마다 재지급)은 2.0 서버 작업에서 같이 막는다(`api/_lib/iapGrant.js`).
- 광고: AdMob 전면, 광고 단위 ID는 `src/ads.js`.
